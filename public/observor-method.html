Measurement methodology

Phenomenon before identity.

OBSERVOR 2.0 investigates identity without presupposing that identity is the phenomenon being measured.

Core sequence

MEASURE → MANIPULATE / ABLATE → OBSERVE → COMPARE → CONSTRUCT

Core conditions

  • H+ — candidate history/property retained.
  • H− — candidate history/property ablated.
  • H−I — history removed internally but equivalent historical information supplied externally.
  • SHAM — manipulation performed without causal ablation.

Key question

What measurable phenomenon disappears when this property disappears?

Interpretation ladder

  1. L0 — observable behavior
  2. L1 — reproducible behavioral pattern
  3. L2 — persistent/distinctive behavioral organization
  4. L3 — causal historical dependence
  5. L4 — candidate identity construct, only if supported by the preceding evidence

Anti-presupposition rule

The instrument does not require self-report, the word “I,” consciousness, intelligence, language, W/V/B/A/N/D labels, or an identity declaration. Identity is a downstream research hypothesis.
